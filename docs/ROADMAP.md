# Roadmap

1. **Foundation** — timeline, entries, uncertain dates, persistence, CRUD, and autosave are complete. Richer revisions remain later work.
2. **Life organization** — people, places, tags, eras, and basic relationship navigation are complete. Advanced search remains.
3. **Media** — durable metadata, local binary storage, thumbnails, and editor attachment UI are complete. Library/gallery and backup tooling remain.
4. **Advanced timeline** — basic drag-assisted date movement and undo are complete; smooth zoom, clusters, age view, and groups remain.
5. **Archive and preservation** — history, backups, robust transfer, book/PDF.
6. **AI assistance** — optional suggestions only; never silent rewriting.
